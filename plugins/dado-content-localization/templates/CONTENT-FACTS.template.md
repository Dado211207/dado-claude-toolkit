# Approved content facts

Copy this into a project as `docs/ai/CONTENT-FACTS.md`, or wherever the project keeps
content documentation, and fill it in **with the owner**.

This file is the single approved source for factual claims in the project's content.
A claim that is not in here is unsupported, and unsupported claims are flagged for
confirmation — never published, never inferred, never filled in with a plausible
value.

> **This file is committed.** In a public repository it is world-readable. It must
> contain only information the owner has agreed to publish. No credentials, no
> private contact details, no private personal data, no third-party personal data,
> no absolute local paths.

given.
